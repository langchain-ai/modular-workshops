# Chinook sample database

`chinook.db` is an unchanged copy of the SQLite fixture from the
[Chinook Database](https://github.com/lerocha/chinook-database) project. It
contains synthetic data for a digital media store and is bundled so the
text-to-SQL workshop does not depend on a runtime download.
